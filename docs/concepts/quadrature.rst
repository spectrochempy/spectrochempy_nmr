Quadrature and metadata
=======================

Quadrature describes how the acquisition encodes the real and imaginary
parts of the signal. The reader records the acquisition mode and calibrates
the axes when the input contains the necessary information.

For 2D acquisitions, the indirect quadrature determines how the plugin
combines traces when transforming F1. Check the
:doc:`2D processing guide <../userguide/processing_2d>` before processing and
the :doc:`complex channels guide <hypercomplex>` before selecting a plane.
For exchanging datasets and working with frequency references, see
:doc:`../reference/interop`.
