Getting started
===============

You can follow these recipes without writing a Python program from scratch.
Copy the cells in order, run them, then change the settings indicated below
each example.

1. :doc:`Install the tools and open a notebook <installation>`.
2. :doc:`Display, zoom and save your first spectrum <quickstart>`.
3. :doc:`Turn a recorded signal into a spectrum </userguide/processing_1d>`.

The examples use a small public Bruker dataset. You do not need your own
measurement to get started. To use your own data afterwards, follow
:doc:`Open your NMR data </userguide/reading_data>`.
