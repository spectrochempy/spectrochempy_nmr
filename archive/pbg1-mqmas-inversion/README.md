# PBG1 MQMAS/MAS case study backup

Withdrawn from the published NMR documentation at the maintainer's request
on 22 November 2026: the results were not sufficiently illustrative for a
user guide. This is a preservation copy for future investigation, outside
the Sphinx sources and the executable gallery. It is not a supported tutorial.

The original guide, complete analysis script, reported metrics and three
figures are retained byte for byte, with their original repository paths
under this directory. `manifest.json` records the source revision and SHA-256
checksums. The original Czjzek guide is also retained to preserve its removed
PBG1 benchmark discussion; the active guide keeps the general model limits.
The archived PBG1 guide records the public dataset's provenance, download
location, licence and checksum. Raw acquisitions are not duplicated here.

To resume, work from a copy of the archived script and the referenced data.
Recheck the model, convergence and interpretation before restoring this
study to the guides. Restoring a published guide would also require updating
its navigation and API links. The generic inversion API and synthetic
MQMAS/MAS guide remain active; withdrawing this case study changes neither.
